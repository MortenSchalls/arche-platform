# Website (archeaviation.com)

`design-source/` is the Claude Design project "Arche Executive Website Strategy". Current version: `Arche Executive v7.dc.html` (v7-print is the print layout). Older versions, screenshots and uploads stay on the Mac in the Design folder and are not part of the code.

The `.dc.html` files render only with `support.js` and `image-slot.js`; images are stored in `.image-slots.state.json`. See docs/MIGRATION.md, "Website", for the conversion to normal pages.
